## **[Проект рынок стартапов](https://github.com/Dmitry-Kozhushko/Practicum_projects/blob/main/Проект%20рынок%20стартапов.ipynb)**

**Цель** — исследовать структуру и динамику венчурного рынка, оценить эффективность различных типов инвестиций и сформулировать рекомендации для инвестора (в условиях 2015 года).

**Задачи:** предобработка данных, сегментация компаний и рынков, работа с выбросами, анализ типов и динамики финансирования, расчёт возврата средств.

**Инструменты:** Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebook, PostgreSQL, Yandex DataLens.

**Ключевые выводы:**
- Рынок смещается в сторону ранних стадий: количество сделок растёт, медианный размер раунда снижается.
- Долгосрочные проекты привлекают основную долю капитала (61.9%).
- Лидеры роста — интернет-технологии, электронная коммерция, облачные решения, мобильные приложения.
- Венчурное финансирование показывает лучший возврат среди всех типов инвестиций.

**Рекомендации:** фокусироваться на интернет-секторах, использовать venture как основной инструмент, seed и angel — для ранних стадий с повышенными рисками.
