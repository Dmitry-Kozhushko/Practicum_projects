# Анализ финансирования стартапов

**Цель проекта** — подготовить датасет к работе, исследовать динамику и структуру финансирования стартапов и ответить на вопросы, важные для оценки инвестиционных стратегий.

---

## Задачи проекта

1. **Предобработка данных**  
   - Удалить дубликаты и пропуски.  
   - Проверить корректность числовых и временных значений.

2. **Сегментация компаний**  
   - Выделить группы компаний по срокам финансирования.  
   - Сравнить их по количеству и объёму инвестиций.

3. **Классификация рынков**  
   - Разделить сегменты рынка на массовые, средние и нишевые.  
   - Учесть классификацию в дальнейшем анализе.

4. **Очистка данных**  
   - Определить типичные и аномальные значения объёмов финансирования.  
   - Исключить выбросы.  
   - Ограничить период исследования.

5. **Анализ типов финансирования**  
   - Сравнить популярность и объёмы разных типов финансирования.

6. **Динамика по годам**  
   - Проанализировать динамику раундов и объёмов инвестиций по годам.  
   - Оценить изменения в массовых сегментах рынка.

7. **Оценка возврата средств**  
   - Рассчитать долю возврата средств для разных типов финансирования.  
   - Оценить устойчивость показателей.

8. **Итоговые выводы и рекомендации**  
   - Сформулировать рекомендации для инвестиций (на 2015 год).
