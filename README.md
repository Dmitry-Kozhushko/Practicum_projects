## **[Проект рынок стартапов](https://github.com/Dmitry-Kozhushko/Practicum_projects/blob/main/Проект%20рынок%20стартапов.ipynb)**

**Цель** — исследовать структуру и динамику венчурного рынка, оценить эффективность различных типов инвестиций и сформулировать рекомендации для инвестора (в условиях 2015 года).

**Задачи:** предобработка данных, сегментация компаний и рынков, работа с выбросами, анализ типов и динамики финансирования, расчёт возврата средств.

**Инструменты:** Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebook, PostgreSQL, Yandex DataLens.

## **[Проверка гипотезы в Python и составление аналитической записки](https://github.com/Dmitry-Kozhushko/Practicum_projects/blob/main/Проверка%20гипотезы%20в%20Python%20и%20составление%20аналитической%20записки.ipynb)**

**Задача** — проверить, проводят ли пользователи из Санкт-Петербурга больше времени в приложении «Я Книги», чем пользователи из Москвы.

**Гипотезы:**
- H₀: среднее время не различается
- H₁: в Санкт-Петербурге время больше

**Инструменты:** Python (Pandas, SciPy), Jupyter Notebook, t-тест (α = 0.05)

## **[Анализ результатов A/B-тестирования](https://github.com/Dmitry-Kozhushko/Practicum_projects/blob/main/Анализ%20результатов%20AB-тестирования.ipynb)**

**Задача** — оценить, увеличивает ли упрощённый интерфейс конверсию зарегистрированных пользователей в покупателей на 3 п.п. в течение 7 дней после регистрации.

**Гипотезы:**
- H₀: конверсия в группе B ≤ конверсии в группе A
- H₁: конверсия в группе B > конверсии в группе A

**Инструменты:** Python (Pandas, NumPy, SciPy, StatsModels), Jupyter Notebook, Z-тест (α = 0.05)
